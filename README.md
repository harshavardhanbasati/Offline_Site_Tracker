# FieldSync

Offline-first field inspection management platform for administrators, inspectors, and employees.

- Frontend: React, TypeScript, Vite, Tailwind CSS, Dexie.js, TanStack Query
- Backend: FastAPI, SQLAlchemy 2.0, PostgreSQL, Alembic, JWT
- Offline: IndexedDB persistent outbox, idempotency, version conflicts, PWA

See `docs/ARCHITECTURE.md`, `docs/MASTER_CHECKLIST.md`, and `docs/DEPLOYMENT.md`.
